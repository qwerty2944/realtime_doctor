# RightHand 의사용 통계 화면 — 사용 안내

> **먼저 읽어 주세요.** 이 서비스는 시연용 데모입니다. 이 화면의 숫자는 **AI가 만든
> 문진 초안을 집계한 값**이며, 확정 진단 통계가 아닙니다. 임상 판단과 최종 결정은
> 전적으로 의료진의 몫입니다. 그리고 **실제 환자 정보는 입력하지 마세요.** 데모
> 데이터로만 확인해 주세요.

---

## 이 문서가 다루는 범위

**웹은 의사용 통계 화면 하나만** 담당합니다.

| 무엇 | 어디서 보나 |
|---|---|
| 통계 (이 문서) | 웹 — `https://entanglecare.com/righthand/doctor` |
| 환자 문진 화면 | 진료실 태블릿의 **키오스크 앱** (별도 배포) |
| 대기 목록, 환자 상세(SOAP/감별진단/추천검사/원본대화), 문헌 근거 | **네이티브 앱** |

> 예전에는 환자 문진도 이 웹 주소(`/righthand/patient`)에 있었습니다. 지금은 키오스크
> 앱으로 옮겼고, 키오스크가 아직 배포되지 않아 그 주소는 열리지 않습니다. 정상입니다.

## 1. 통계 화면 사용법

1. `https://entanglecare.com/righthand/doctor` 를 엽니다.
2. 발급받은 의료진 이메일·비밀번호로 로그인합니다.
3. 로그인하면 **통계** 화면이 바로 열립니다.

보여 주는 것:

- **문진 완료 건수** — 문진이 시작만 되고 끝나지 않은 건은 빠집니다.
- **레드플래그 건수** — 응급 의심 표시가 붙은 건수.
- **평균 문진 소요 시간** — 환자가 문진을 시작한 시각부터 결과가 저장된 시각까지의
  실제 경과 시간입니다. 아래 "집계 대상 건수"는 이 평균에 실제로 반영된 건수입니다.
- **날짜별 내원 추이** / **질환별 분포** / **주소증별 분포**
- **CSV 내보내기** — 화면에 보이는 내용을 그대로 파일로 받습니다.

기간은 오늘 / 이번 주 / 이번 달 / 사용자 지정 중에 고를 수 있습니다. 날짜 기준은
한국 시간(Asia/Seoul)이며, 주는 월~일로 봅니다.

로그인 계정 정보는 배포를 준비한 담당자에게 문의하세요.

> 예전 주소 `/dashboard` 로 만들어 둔 링크는 새 주소로 자동 이동됩니다.

---

## 2. 숫자를 읽을 때 주의할 점

- **질환별 분포는 확정 진단이 아닙니다.** AI가 문진 대화에서 뽑아낸 감별진단 후보 중
  1순위를 세는 값입니다. 시스템은 의사가 실제로 어떤 진단을 내렸는지 **알지 못합니다.**
  그래서 "확정 진단 건수"라는 항목은 아예 만들지 않았습니다 — 항상 0을 가리키는 칸을
  두는 것보다 없는 편이 정직합니다.
- **본인의 숫자만 보입니다.** 로그인한 의사에게 기록된 진료만 집계됩니다.
- **환자 식별정보는 화면에도 CSV에도 들어가지 않습니다.** 집계 함수 자체가 환자 이름·
  생년월일·등록번호·전화번호·환자 id·진료 id를 반환하지 않습니다.
- **레드플래그는 안전을 위해 넓게 잡습니다** — 경고가 떠도 실제 응급이 아닐 수 있고,
  반대로 모든 응급을 잡는다고 보장하지도 않습니다.

---

## 3. CSV 내보내기에 대해

내보내기를 누르면 **누가 언제 어느 기간의 집계를 받아 갔는지**가 기록으로 남습니다.
파일 자체에는 환자 식별정보가 없지만, 클리닉 전체 숫자를 누가 가져갔는지는 나중에
반드시 물어보게 되는 질문이라 남깁니다.

기록에 실패하면 **다운로드가 되지 않습니다.** 기록 없이 파일만 나가는 상태를 허용하지
않기 때문입니다.

## 4. 꼭 기억할 점

- 이 화면의 임상 관련 숫자는 **AI 초안 기반 집계**이며 **진단 통계가 아닙니다.**
- **실제 환자 정보를 입력하지 마세요.** 이 배포는 데모이며 가상 데이터 전용입니다.
- 문진에서 만든 데이터는 네이티브 앱의 관리자 화면에서 삭제할 수 있습니다. 시연이 끝나면
  정리해 주세요.
